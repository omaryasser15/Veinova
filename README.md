# Veinova – Mobile Blood Bank App

## 1. Project Name
**Veinova – Mobile Blood Bank Application**

## 2. Project Idea
Veinova is a mobile blood bank application designed to connect blood donors, patients in urgent need, and charitable organizations through a single platform. It aims to simplify donor registration, emergency blood requests, donation campaign tracking, and financial contributions to charitable cases. The app will also support NGOs in coordinating blood donation campaigns and managing blood inventory.

## 6. KPIs (Key Performance Indicators)

The following KPIs will be used to monitor project progress and evaluate the quality of the final deliverables:

- **Task Completion Rate:** Track completed tasks against the total assigned tasks.
- **Milestone Completion:** Monitor progress against the agreed project timeline.
- **Design Coverage:** Ensure all agreed-upon screens and user flows are completed.
- **Design Consistency:** Maintain consistent colors, typography, and UI components.
- **Usability Testing:** Conduct usability testing and document user feedback.
- **On-Time Delivery:** Complete and submit project deliverables by the agreed deadline.
- **Team Collaboration:** Ensure regular communication, design reviews, and shared progress updates.
